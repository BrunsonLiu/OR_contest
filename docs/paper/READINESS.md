# 开题条件核对：现在还不能开始写论文

本文按项目标准逐条核对“开题条件是否全部满足”。结论：**未满足**。在缺口、算法和证据三项里，至少两项没有过关；此时开始写论文会把未验证的假设写成结论。

## 1. 条件与现状

| 条件 | 要求 | 现状 | 判断 |
| --- | --- | --- | --- |
| 新问题定义 | 主体、对象、信息顺序、行动、终止、评价，一页写清 | B（顾客确认拣货）有[模型草案](MODEL.md)与一页定义；Pivot B（仓网选品×确认）只有[开题卡](PIVOT_B.md) | 部分满足；Pivot B 未建模 |
| 最近邻逐篇对照 | 具体定义、信息、行动、耦合、结论，注明正文位置 | B 的最近邻（Lorenz 2024、Bhowmick 2024、Chen 2019、Giannikas 2017、Brubach、Bekci 2024）已读正文；Pivot B 的最近邻 COR 2026 全文未取得 | B 满足；Pivot B 证据不足 |
| 四项检查 | 去行业名、冻结机制、判别实例、机制—模型—算法—实验对应 | B 已做；E1 的 504 个实例支持机制有决策后果 | 满足到机制层，未到算法层 |
| 算法贡献 | 经典基线 + 针对机制的改进 + 同预算消融 | B 的精确 DP 在 E6 中被补全后的规则族 0/16 追平；没有改进算法 | **不满足** |
| 实验证据 | 正确性、算法、机制、政策四类 | E1—E6 只有小实例；没有可扩展算法比较，没有真实数据 | 部分满足 |
| 现实证据 | 业务流程、参数、数据来源 | Instacart 文档支持流程；缺未回复默认动作、结束权限、回复时延与日志 | 部分满足 |

## 2. 结论

- B 的机制是真的，但当前模型类没有算法空间：规则族补全后完整 DP 不再更好。按“新问题 + 改进经典算法 + 实验验证”的三项要求，B 不足以作为论文主线。
- Pivot B 的故事线有成本结构支撑，最小检查也显示确认成本能改变仓库与选品；但最近邻 COR 2026 全文被 403，缺口未核实，不能立项。2026-10-27 夜间又试 Crossref、OpenAlex、Unpaywall、zbmath、NSTL、Tecmilenio、lib.hmc.edu.cn，均无法取得全文或摘要；只有关键词，不能当全文证据。
- A（多订单共享替代）与 C（回复相关性）尚未检验。A 是最后一个可能撑起算法的小模型；若规则族又追平，B 线整体停止。

## 3. 现在能做什么、不能做什么

不能做：

- 不能把 B 的机制检查写成“算法有效”。
- 不能把 Pivot B 的题录当 gap 证据。
- 不能用合成参数写现场建议。

可以做：

1. 拿到 COR 2026 全文，核对 Pivot B 是否已被覆盖；若未覆盖，再做多门店多 SKU 的最小检验。
2. 检验 A：两个订单争一件替代，看规则族是否被精确 DP 追平；这是最后一个可能撑起算法的小模型。
3. 若 A 也被追平、COR 2026 又覆盖 Pivot B，则换问题，不在旧候选上改标题。

## 4. 写作门槛

只有以下三项同时成立，才开始写论文：

1. 缺口在最接近的具体工作上逐条对照过，未读的标“未读”而不是“没有”；
2. 有一个可执行的基线，和一个针对核心机制的改进，且同信息、同预算下有稳定差异；
3. 机制、算法、实验三层的证据能一一对应，失败和边界都保留。

当前第 2 项不成立，第 1 项在 Pivot B 上不成立。先把这两项补齐，再动笔。
