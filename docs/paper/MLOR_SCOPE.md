# MLOR 问题边界表

> 2026-10-31。目的：把“已经定死的”和“还没定的”分开。未定项会改变模型、算法或结论，写作前必须逐项决定。

## 一、已经定死的

| 维度 | 本文设定 |
| --- | --- |
| 决策主体 | 一个冷链仓网计划员 |
| 信息 | 候选仓位置与开仓成本、仓批次年龄、门店 MLOR、需求、距离/时间、车辆容量、保质期 |
| 行动顺序 | 开仓 → 门店分配 → 路线/顺序 → 用哪个仓的货 → 未服务 |
| 时间 | 单周期、确定性 |
| 网络 | 仓 → 店，单层 |
| 库存 | 每仓一个批次、一个年龄；不做仓内多批次混合 |
| 需求 | 单位需求，每店每期最多访问一次 |
| MLOR | 到货剩余保质期 `L − a − T ≥ m_j` 的硬约束；不满足则该店不可由该仓服务 |
| 成本 | 开仓 + 车辆固定 + 运输（距离）+ 未服务惩罚 |
| 求解 | 8/12 店精确子集 DP；20 店年龄可行 ALNS |

## 二、没定死 / 没建模的

| 维度 | 现状 | 后果 |
| --- | --- | --- |
| 网络层级 | 只做仓→店；“冷链仓网”容易让人以为是 CDC→RDC→店两层 | 若审稿人按两层理解，模型与赛题背景不一致；要么改称单层，要么补 CDC→RDC |
| MLOR 语义 | 当作到货验收硬门槛；不建模门店库存、上架时间、消费者剩余 | 如果 MLOR 实际是“上架时剩余”，模型少了门店库存与销售过程 |
| 拒收后处理 | 只记“未服务 + 惩罚 200”；不建模退货、报损、补送、折价 | 惩罚不是经济拒收成本，敏感性结论只是模型内结论 |
| 需求 | 单位需求、一店一次 | 赛题城市 50—100 吨/天，装不下；拆分配送/多趟未建模 |
| 时间 | 单周期 | 年龄不演化、不补货；多周期下“先用老货”的取舍完全不同 |
| 库存 | 每仓单批次 | 多批次混合、FIFO 出库未建模；“用哪批货”实际退化成“用哪个仓” |
| 成本 | 运输按距离，不含持有、废弃、折价、缺货 | 成本口径不完整，不能直接对比企业账 |
| 不确定性 | 需求、时间、年龄都确定 | 随机到货/交通/需求未处理 |
| 车辆 | 同质、容量 4 店 | 多车型、载重吨、司机工时未建模 |
| 温区 | 单温区 | 多温区（冷冻/冷藏）未建模 |
| 数据 | 合成 + 赛题点位示意（单位需求） | 没有企业数据；示意不能当现场结论 |
| 文献 | MLOR 概念已有 Singh & Kuthambalayan 2022（CIE，closed）；TRSC 2018 近；Omega 2019 closed | 差异未确认；不能称新问题 |

## 三、写作前必须决定的四件事

1. **MLOR 是硬验收还是软目标？** 硬验收：当前模型；软目标：需要把“低于门槛的货”建成折价/降级，而不是不可行。
2. **门店库存建不建？** 不建：MLOR 只是到货条件；建：要加门店库存状态、上架/销售、剩余保质期演化，模型变成多周期。
3. **单层还是两层？** 单层：改称“仓—店配送”；两层：补 CDC→RDC 的年龄与运输，赛题背景才完整。
4. **单位需求还是吨/拆分配送？** 单位需求：保留现有 DP/ALNS；吨/拆分：重做容量、成本、DP/ALNS，另开研究。

## 四、结论

- 核心机制（年龄—距离—门槛）是清楚的。
- 问题边界**没有全部清楚**：网络层级、MLOR 语义、拒收处理、需求单位、单/多周期都还没定死。
- 这些不是措辞问题，是模型问题；不决定就不能写“问题定义”，也不能把结论外推到真实冷链。
