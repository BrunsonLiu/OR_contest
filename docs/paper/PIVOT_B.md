# B 方向开题卡：仓网选品宽度与门店确认工作量

换向判别卡把 B 列为优先方向。本文只写四段骨架和撤回条件，未做文献全文对照，也未建模；引用只到题录/摘要，标“待核实”。

## 一、背景

生鲜电商的仓网不只决定“货从哪来”，还决定“每个仓配哪些 SKU”。配得窄，门店更容易缺货；缺货会触发替代确认，确认要花拣货员工时、可能被拒、产生返拣。平台现在算仓网成本时，通常只算开仓、运输、损耗和处置，不把下游确认工作量算进去。

现实对应：同一 SKU 不必每个仓都配；越靠近门店的仓配得越宽，缺货和确认越少，但库存占用和仓储成本越高。这是“选品宽度—缺货—确认”的真实权衡。

## 二、Gap（待核实）

已读到的相邻工作：

- 选品与配送联合规划：`Integrated assortment and distribution planning in vendor-managed inventory systems`（COR 2026，题录/摘要）。它把选品和配送一起做，但没有把“缺货触发的顾客确认工作量”作为下游成本。
- 履约决策：`Making Better Fulfillment Decisions on the Fly in an Online Retail Environment`（INFORMS 博客介绍）。动态履约选择，未处理确认任务生成。
- 缺货与横向调拨：TU/e 的库存/调拨材料把缺货与调拨连接，但不含顾客确认。
- 顾客确认拣货：本仓库 B 线的模型；单订单，不含仓网选品。

**Gap 假设**：网络设计把缺货当作缺货率参数或直接丢失销售；门店履约把选品当作给定。没有工作把“选品宽度 → 缺货频率 → 确认工作量 → 网络成本”接起来。这个假设只覆盖已读范围，需逐篇核对 COR 2026 与横向调拨文献。

## 三、故事线（从成本结构推）

多配一个 SKU 的边际收益 = 减少的缺货损失 + 减少的确认工作量（拣货工时、返拣、拒绝后的退款/流失）；边际成本 = 库存占用、仓储与补货成本。

确认工作量随缺货频率上升；缺货频率随选品宽度下降。若确认成本高，最优选品更宽、仓更靠近门店；若确认成本低，集中化仍最优。存在一个由“确认成本/库存成本”比值决定的阈值，网络结构在阈值两侧切换。

可证伪命题：把确认成本从 0 调到高值，最优开仓数与选品宽度应发生方向性变化；若网络不变，撤回。

## 四、模型骨架

- 集合：候选仓、门店、SKU、温度/品类。
- 决策：开仓、每仓 SKU 集合（选品宽度）、流量、缺货/替代处理。
- 缺货概率：用选品宽度与需求的近似（如报童/泊松缺货率）映射，不假装是精确库存仿真。
- 确认成本：每次缺货的期望确认工时 × 人工成本 + 拒绝/返拣的期望成本。
- 目标：开仓 + 运输 + 损耗 + 库存 + 确认成本。
- 结构：选品 0-1 × 缺货概率非线性；分段线性化后仍是大型 MILP。

## 五、算法骨架

- 基线：不考虑确认成本的网络设计 MILP；以及“先定网络、再按缺货率估算确认成本”的顺序法。
- 改进候选：把确认成本放进主问题，用分段线性缺货率 + Benders（主问题选址/选品，子问题确认工作量与流量）；用缺货率的凸性生成割。
- 消融：去掉确认成本项，比较网络与总成本；确认成本参数扫描。
- 失败条件：计入确认成本后网络不变，或改进算法与基线同预算无差异。

## 六、最小检验与撤回

1. 两仓、若干门店、若干 SKU；选品宽度用参数化缺货率；确认成本从 0 到高值扫描。
2. 比较“忽略确认成本”和“计入确认成本”的最优开仓/选品；看是否出现方向性变化。
3. 若网络不变，撤回 B；若变化，再做算法与数据。

**条件性最小检验（2026-10-27，`assortment-check-20261027`）**：一店、两仓、八 SKU；近仓固定费高、运输低、持有高，远仓相反；未配 SKU 按每件确认成本计。确认成本为 0 时最优是近仓、选品 0；确认成本 5 时最优是远仓、选品 8；切换发生在 1.5—2.0 之间。

这只说明“确认成本可以改变仓库与选品宽度”，不证明文献缺口，也不证明参数方向在真实数据下成立；缺货到确认的映射是线性假设。记录见 `results/experiments/assortment-check-20261027/`。
