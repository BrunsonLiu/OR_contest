# 模型草案：顾客确认未完成时的门店拣货

本文把已实现并核对过的小实例模型写成论文第四节可用的草案。它对应 `src/analysis/confirm_instance_check.py`、`confirm_policy_compare.py`、`confirm_scale.py`、`confirm_multi.py`、`confirm_grid2d.py`，不是已定稿的论文模型。

## 1. 集合与参数

- 门店内节点集合 \(V\)，仓库/起点 \(0\in V\)，货架节点 \(v\in V\setminus\{0\}\)。
- 商品集合 \(I\)。缺货商品 \(a\) 在货架 \(v_a\)；其替代品 \(s\) 在货架 \(v_s\)，价值 \(w_s\)。其它商品 \(i\in I\setminus\{a\}\) 在 \(v_i\)，价值 \(w_i\)。
- 行走时间 \(d_{uv}\)（线状实例取坐标差，二维实例取曼哈顿距离）。
- 交接截止 \(D\)；确认窗口 \(C\le D\)。请求只能在订单仍处于拣货状态时执行，窗口关闭后到达的回复不可用。
- 回复时延 \(R\) 的分布 \(p(r)=\Pr(R=r)\)，生存函数 \(S(u)=\Pr(R>u)\)；拒绝概率 \(q\)，与 \(R\) 独立。
- 请求在第一次到达 \(v_a\) 时发出；更晚发出只会推迟可用时点。

## 2. 状态

\[
x=(t,\ \text{pos},\ M,\ \sigma,\ \text{age})
\]

- \(t\)：当前时刻；\(\text{pos}\in V\)：拣货员位置。
- \(M\subseteq I\)：已拣商品集合。
- \(\sigma\in\{0,1,2,3\}\)：未请求 / 待回复 / 已同意 / 已拒绝或不可用。
- \(\text{age}\)：待回复请求已等待的分钟数；非待回复状态取 0。

多缺货点时，每个请求各有一组 \((\sigma_j,\text{age}_j)\)，状态为这些分量的笛卡尔积。

## 3. 决策

- 移动到相邻/任意节点 \(v\)，耗时 \(d_{\text{pos},v}\)；
- 在当前位置拣货（耗时 0）：替代品需 \(\sigma=2\)，其它商品无状态限制；
- 原地等待 1 分钟；
- 停止（结束本单）。

请求不是单独动作：第一次到达 \(v_a\) 时自动发出；是否访问 \(v_a\) 本身是决策，因此“跳过缺货点”与“请求”在模型里同等合法。

## 4. 转移

在一个耗时 \(\Delta\) 的动作中，若请求处于待回复：

\[
\Pr(\text{同意})=\ (1-q)\left(1-\frac{S(\text{age}+\Delta')}{S(\text{age})}\right),\qquad
\Pr(\text{拒绝})=\ q\left(1-\frac{S(\text{age}+\Delta')}{S(\text{age})}\right),
\]

其中 \(\Delta'=\min(t+\Delta,C)-t\) 是落在窗口内的等待时长；剩余概率使状态保持待回复并把年龄增加 \(\Delta'\)（若动作跨过 \(C\)，则转为不可用）。多个请求的转移按独立分布取乘积。

## 5. 目标与递推

\[
\max\ \mathbb{E}\left[\sum_{i\in M_T} w_i\right]
\quad\text{s.t.}\quad t\le D,
\]

\(T\) 为停止时刻。精确 DP 为

\[
V(t,\text{pos},M,\sigma,\text{age})=
\max\Big\{\ \sum_{i\in M}w_i,\ \max_{v} \mathbb{E}\big[V(t+d_{\text{pos},v},v,M',\sigma',\text{age}')\big]\ \Big\},
\]

拣货动作把对应商品加入 \(M\)。实现中对方程做时间离散和后向递推，小实例可直接枚举。

## 6. 两个可执行基线

- **逐点等待**：到达 \(v_a\) 后等到回复或窗口关闭，再按最近邻服务其余商品；同意则先取替代。
- **走完再回**：到达 \(v_a\) 后立即按最近邻服务其余商品，最后回到 \(v_s\)，若回复已同意且在窗口内则取替代。

二维比较还加了**阈值规则**：按“期望替代价值 / 额外绕路分钟”决定是否访问 \(v_a\)，其余同“走完再回”。这些规则都拥有与完整策略相同的“是否请求”行动，避免基线被削弱。

## 7. 规模与算法空白

- 状态数约为 \(D\cdot|V|\cdot 2^{|I|}\cdot 4\cdot C\)；多缺货点时年龄维度变成 \((C+1)^m\)，精确 DP 迅速不可算。
- 线状实例中“走完再回”已接近最优；二维偏离路线时，完整策略在 4/16 个实例上仍高于最强规则，最大差 1.0（总价值 5）。
- 因此算法问题应表述为：在多个待回复请求、二维布局和窗口约束下，如何用状态聚合、rollout 或分支定界逼近精确 DP，并在同信息、同预算下与上述规则比较。当前没有实现这一步，也没有真实回复数据。

## 8. 可检验命题

1. 回复时延确定且替代品在现有路线上时，完整策略与“走完再回”同解；时延不确定且替代品偏离路线时，两者可能分叉。
2. 若规则被赋予同样的“跳过缺货点”与“等待时长”选择，完整策略的剩余优势应主要来自请求时点与路线顺序，而不是基线缺失行动。
3. 在二维实例中，完整策略的优势应随替代品绕路成本增加而增加；线状实例中应接近零。

命题 2、3 尚未系统检验；当前证据只覆盖到命题 1 和二维的初步比较。
