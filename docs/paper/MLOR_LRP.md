# 冷链 LRP + 剩余保质期门槛（MLOR）：一页定义（草案，2026-10-28）

> 方向已定：仓网、冷链、LRP。叠加的机制是“仓库库存年龄 × 运输时间 × 门店最低剩余保质期”。文献排重今天被 API 限流挡住，状态标“待查”，不宣称新颖。

## 1. 问题

两层冷链网络：候选仓、门店、单一温区（先做冷藏）。每个仓持有不同生产日期的批次，即库存年龄 a。产品保质期 L。门店 j 要求到货时剩余保质期不低于 MLOR_j（最小剩余保质期，常见于商超合同）。

决策：开哪些仓；每个门店由哪个仓服务；车辆路径与访问顺序；每个门店用哪个年龄的批次。

关键关系：运输时间会吃掉剩余保质期。从仓 i 的年龄 a 批次发货，到门店 j 的到货剩余为

```text
remaining = L − a − travel_time(i, j 的访问时刻)
```

必须满足 `remaining ≥ MLOR_j`。所以同一个仓，老批次只能服务近店或低 MLOR 店；新鲜批次要留给远店或高 MLOR 店。

成本：开仓、运输（吨公里）、冷藏能耗、过期/不可用批次的废弃、缺货惩罚。

## 2. 故事线（从成本结构推）

库存年龄是负债，不是免费的库存。老一批货的“有效服务半径”更短：运输每多一小时，剩余保质期就少一小时；超过 MLOR 就只能废弃或降级。

于是开仓、分配、路径、批次选择不能分开：

- 老库存仓适合服务近店、低 MLOR 店，用低价库存避免废弃；
- 远店、高 MLOR 店必须由新鲜库存仓服务，哪怕运输更贵；
- 如果某个仓的库存整体偏老，它的最优服务范围会缩小，可能不如不开；
- 忽略年龄，会把“账面可用库存”当成“可交付库存”，低估废弃和缺货。

可检验含义：同一网络，按平均年龄或零年龄规划，会把老批次派给远店，账面可行、执行不可行；年龄感知的 LRP 会改变门店分配和路径，并减少废弃/缺货。

## 3. 最小判别（修正后通过）

2 个仓、3 个门店、1 个温区、每仓一条路线、容量 2；L=6 天；W_fresh 在 (0,0) 年龄 0，W_old 在 (100,0) 年龄 4.8；100 km = 1 天。

- S1 (110,0)，MLOR=1；W_old 0.1 天，剩余 1.1，可行。
- S2 (100,10)，MLOR=3；W_old 0.1 天，剩余 1.1，不可行；W_fresh 1.1 天，剩余 4.9，可行。
- S3 (0,10)，MLOR=1；W_fresh 0.1 天，剩余 5.9；W_old 1.1 天，剩余 0.1，不可行。

| 方案 | 分配 | 计划成本 | 实际成本 | 不可行 |

## 4. 四项检查

1. **删去行业名称**：问题是“库存年龄 × 运输时间 × 最低剩余保质期的选址—路径”，不依赖冷链字眼；应按易腐品配送定位。
2. **冻结机制**：所有批次同年龄 → 退化为标准 LRP；MLOR=0 → 退化为普通保质期约束；两种冻结都应让“年龄匹配”消失。
3. **判别实例**：上面的 2 仓 3 店，手算可核。
4. **机制—模型—算法—实验对应**：模型是年龄分层的 LRP（批次年龄、到货剩余、MLOR、路径）；算法候选是年龄可行的插入/ALNS；实验先最小枚举，再中等规模。三者要一一对应。

## 7. 8 店精确 DP（2026-10-28，`mlor-dp-20261028`）

3 个仓（年龄 0、2.5、4.5）、8 个门店、每车容量 4；按门店子集做集合划分，路线顺序全枚举。年龄感知只允许所有门店到货剩余 ≥ MLOR 的路线；年龄盲按年龄 0、不做 MLOR 检查选最便宜路线，再按真实年龄加惩罚。

| 指标 | 结果 |
| --- | --- |
| 年龄感知更好 | 9/10 |
| 年龄盲更好 | 0/10 |
| 平均差（感知−盲实际） | −1051.3 |
| 年龄盲不可行总数 | 54（10 个实例） |
| 种子 0 | 年龄感知 647.6；年龄盲计划 635.4，实际 2235.4，8 个不可行 |

读法：年龄盲的计划只便宜 12，执行时 8 个门店剩余不足，罚 1600，实际贵 1587。精确 DP 下机制仍然成立，而且差距很大。

边界：合成实例、单 SKU、单温区、每子集只取一个最小成本顺序、惩罚 200；不是现场结论。文献排重仍未完成（易腐 IRP 很近，见第 5 节）。
