# 冷链 LRP + 剩余保质期门槛（MLOR）：一页定义（草案，2026-10-28）

> 方向已定：仓网、冷链、LRP。叠加的机制是“仓库库存年龄 × 运输时间 × 门店最低剩余保质期”。两篇最近邻已读全文（COR 2019 无 shelf life；TRSC 2018 有剩余保质期但无门店门槛），Omega 2019 仍未读；不宣称已确认空白。

## 1. 问题

两层冷链网络：候选仓、门店、单一温区（先做冷藏）。每个仓持有不同生产日期的批次，即库存年龄 a。产品保质期 L。门店 j 要求到货时剩余保质期不低于 MLOR_j（最小剩余保质期，常见于商超合同）。

决策：开哪些仓；每个门店由哪个仓服务；车辆路径与访问顺序；每个门店用哪个年龄的批次。

关键关系：运输时间会吃掉剩余保质期。从仓 i 的年龄 a 批次发货，到门店 j 的到货剩余为

```text
remaining = L − a − travel_time(i, j 的访问时刻)
```

必须满足 `remaining ≥ MLOR_j`。所以同一个仓，老批次只能服务近店或低 MLOR 店；新鲜批次要留给远店或高 MLOR 店。

成本：开仓、运输（吨公里）、冷藏能耗、过期/不可用批次的废弃、缺货惩罚。

## 2. 故事线（从成本结构推）

库存年龄是负债，不是免费的库存。老一批货的“有效服务半径”更短：运输每多一小时，剩余保质期就少一小时；超过 MLOR 就只能废弃或降级。

于是开仓、分配、路径、批次选择不能分开：

- 老库存仓适合服务近店、低 MLOR 店，用低价库存避免废弃；
- 远店、高 MLOR 店必须由新鲜库存仓服务，哪怕运输更贵；
- 如果某个仓的库存整体偏老，它的最优服务范围会缩小，可能不如不开；
- 忽略年龄，会把“账面可用库存”当成“可交付库存”，低估废弃和缺货。

可检验含义：同一网络，按平均年龄或零年龄规划，会把老批次派给远店，账面可行、执行不可行；年龄感知的 LRP 会改变门店分配和路径，并减少废弃/缺货。

## 3. 最小判别（修正后通过）

2 个仓、3 个门店、1 个温区、每仓一条路线、容量 2；L=6 天；W_fresh 在 (0,0) 年龄 0，W_old 在 (100,0) 年龄 4.8；100 km = 1 天。

- S1 (110,0)，MLOR=1；W_old 0.1 天，剩余 1.1，可行。
- S2 (100,10)，MLOR=3；W_old 0.1 天，剩余 1.1，不可行；W_fresh 1.1 天，剩余 4.9，可行。
- S3 (0,10)，MLOR=1；W_fresh 0.1 天，剩余 5.9；W_old 1.1 天，剩余 0.1，不可行。

| 方案 | 分配 | 计划成本 | 实际成本 | 不可行 |
| --- | --- | --- | --- | --- |
| 年龄盲（年龄 0） | W_old：S1、S2；W_fresh：S3 | 220 | 420 | 1（S2 剩余 0.9） |
| 年龄感知 | W_fresh：S3、S2；W_old：S1 | 260 | 260 | 0 |

年龄感知低 160（260 对 420）。第一版失败的原因是没限制每仓路线数，新鲜仓可以开多条路线接走所有店；修正后每仓一条路线、容量 2，判别成立。记录 `mlor-check-20261028b`。

在判别实例通过之前，MLOR 这条线只停在 P0 定义，不建模、不写论文。现在判别通过，可以进入模型，但文献排重还没完成。

## 4. 四项检查

1. **删去行业名称**：问题是“库存年龄 × 运输时间 × 最低剩余保质期的选址—路径”，不依赖冷链字眼；应按易腐品配送定位。
2. **冻结机制**：所有批次同年龄 → 退化为标准 LRP；MLOR=0 → 退化为普通保质期约束；两种冻结都应让“年龄匹配”消失。
3. **判别实例**：上面的 2 仓 3 店，手算可核。
4. **机制—模型—算法—实验对应**：模型是年龄分层的 LRP（批次年龄、到货剩余、MLOR、路径）；算法候选是年龄可行的插入/ALNS；实验先最小枚举，再中等规模。三者要一一对应。

三篇最近邻，两篇已读全文，一篇只到题录。

| 工作 | 读到什么 | 覆盖到哪里、缺什么 |

判定：TRSC 最近，但它的 TSL 是缺货概率，不是门店到货剩余门槛；COR 无保质期。`门店 MLOR × 仓库年龄 × LRP` 仍是**差异待检验**；Omega 是 closed access，未读是风险。不能宣称已确认空白。

## 6. 风险

- TRSC 2018 已有剩余保质期 IRP；若 Omega 2019 含门店到货门槛，撤回。
- 单温区、单批次年龄层是简化；多温区、多批次会更大。
- 没有企业数据；L、年龄、MLOR 先用透明合成参数，明确不作现场结论。

## 7. 8 店精确 DP（2026-10-28，`mlor-dp-20261028`）

3 个仓（年龄 0、2.5、4.5）、8 个门店、每车容量 4；按门店子集做集合划分，路线顺序全枚举。年龄感知只允许所有门店到货剩余 ≥ MLOR 的路线；年龄盲按年龄 0、不做 MLOR 检查选最便宜路线，再按真实年龄加惩罚。

| 指标 | 结果 |
| --- | --- |
| 年龄感知更好 | 9/10 |
| 年龄盲更好 | 0/10 |
| 持平 | 1/10 |
| 平均差（感知−盲实际） | −1051.3 |
| 年龄盲不可行总数 | 54（10 个实例） |
| 种子 0 | 年龄感知 647.6；年龄盲计划 635.4，实际 2235.4，8 个不可行 |

读法：年龄盲的计划只便宜 12，执行时 8 个门店剩余不足，罚 1600，实际贵 1587。精确 DP 下机制仍然成立，而且差距很大。

边界：合成实例、单 SKU、单温区、每子集只取一个最小成本顺序、惩罚 200；不是现场结论。文献：COR 2019 无 shelf life；TRSC 2018 有剩余保质期但无门店到货门槛；Omega 2019 为 closed access、未读（见第 5 节）。

## 9. 20 店 ALNS（2026-10-28，`mlor-alns-20261028b`）

3 仓、20 店、容量 4；年龄感知贪心初解 + 破坏—修复 ALNS：每轮移除 2—4 个已服务门店，再抽 1—2 个未服务门店一起重插，200 轮。

| 指标 | 结果 |
| --- | --- |
| 改进实例 | 10/10 |
| 平均改进 | 1280.1 |
| 种子 0 | 2317.5 → 1201.7 |

初解有 7 个未服务门店（构造限每仓 2 条路线）；ALNS 允许更多路线并把它们插回去，所以改进同时来自“多服务门店”和“路径更省”。

边界：20 店没有精确基准；这是启发式对贪心的改进，不证明最优性；合成参数、单 SKU/温区。下一步要给下界或小规模精确对比，并做参数/消融。

## 11. 12 店 ALNS 消融（2026-10-28，`mlor-ablation-20261028b`）

三个变体都强制 MLOR 硬约束，差别只在破坏—修复和未服务重插：

| 变体 | 平均差（对精确） | 最大差 | 达到最优 |
| --- | --- | --- | --- |
| 贪心初解 | 473.4 | 795.5 | 0/10 |
| 去未服务重插 | 280.9 | 614.7 | 1/10 |
| 完整 ALNS | 15.85 | 124.45 | 7/10 |

读法：破坏—修复把平均差距从 473 降到 15.9；未服务重插贡献最大（280.9→15.9）。这支持“算法部件针对核心机制”的说法：老库存仓会留下高 MLOR 门店，必须允许重插才能把它们放到新鲜仓。

没有列入“去掉年龄可行性”的变体：它允许不可行解、只罚 200，和硬约束精确 DP 不可比。

## 12. 拒收惩罚敏感性（2026-10-28，`mlor-sensitivity-20261028`）

8 店精确 DP，5 个种子；门店拒收/折价惩罚从 0 取到 800。

| 惩罚 | 平均差（年龄盲−年龄感知） | 年龄感知更好 |
| --- | --- | --- |
| 0 | −36.4 | 0/5 |
| 50 | 223.6 | 5/5 |
| 100 | 483.6 | 5/5 |
| 200 | 1003.6 | 5/5 |
| 400 | 2043.6 | 5/5 |
| 800 | 4123.6 | 5/5 |

读法：惩罚为 0 时，年龄盲反而便宜 36.4（它只多跑一点运输、没有罚）；惩罚 50 时，年龄感知已经好 223.6。平均每个实例约 5.2 个不可行交付，盈亏平衡的拒收惩罚约 7/次；现实中的拒收、折价、报损远高于 7，所以年龄感知有实际价值。

边界：合成实例；惩罚是模型参数，不是实测折价；不能据此给企业定价建议。

## 13. 20 店 LP 下界（2026-10-28，`mlor-bound-20261028`）

按仓枚举 ≤4 店的年龄可行路线（20 店只有 1064 条可行），解集合划分的 LP 松弛：允许分数路线和分数开仓，目标含开仓、车辆、运输；与年龄感知 ALNS 比。

| 指标 | 结果 |
| --- | --- |
| 有效实例 | 5/5 |
| 平均相对差 | 9.0% |
| 最大相对差 | 14.1% |
| 种子 0 | 下界 1092.15，ALNS 1201.71，差 10.0% |

读法：LP 很松（分数路线、分数开仓），所以真实最优差距不超过 9%—14%；ALNS 在松弛界附近，但这不是最优性证明。

边界：LP 弱；ALNS 成本含未服务惩罚，LP 假设全服务；不能把 9% 当最优性证明。

## 14. 机制 2×2 消融（2026-10-28，`mlor-mechanism-20261028`）

8 店、5 个种子；把“年龄”和“MLOR”各自打开/关掉，看年龄感知相对年龄盲的差：

| 配置 | 平均差 | 年龄感知更好 |
| --- | --- | --- |
| 年龄 + MLOR（原问题） | 1003.6 | 5/5 |
| 只留 MLOR（仓全新鲜） | 74.0 | 2/5 |
| 只留年龄（门店门槛全 0） | 581.6 | 3/5 |
| 两者都去掉（只剩冷链标签） | 0.0 | 0/5 |

读法：

- 只剩冷链标签时，年龄感知和年龄盲完全一样——标签本身不产生决策差。
- 只留 MLOR：门槛变成到货截止，但仓全新鲜，差只有 74.0。
- 只留年龄：门槛为 0，老库存 + 长路线仍会坏货，差 581.6。
- 两者合起来 1003.6，大于 74.0 + 581.6——匹配“年龄—距离—门槛”的交互才是机制。

边界：8 店、5 种子、合成；年龄盲用同一组路线在各配置下评估，不是独立重优化。

## 16. 需求重量扩展的失败记录（2026-10-28）

尝试把容量从“每车 4 店”改成“吨”，用赛题 23 天日均需求（城市 50—100 吨/天），运输费按载重计。

| 设置 | 结果 |
| --- | --- |
| 30 吨车 | 单车装不下一个城市，路线退化为单店直送 |
| 150 吨车 | 路线仍是单店/双店，ALNS 改进 0.0 |
| 惩罚 200 | 相对百万级运输费可忽略；年龄盲 4.15M，年龄感知 9.78M，盲反而便宜 |
| 改动 | 已撤回，未提交、未形成可引用结果 |

根因不是参数，是模型假设：**每店每期只访问一次 + 单位需求**。真实需求要拆分配送或多趟，精确子集 DP 和现有 ALNS 都不适用；惩罚也要按拒收/折价经济性重新标定。

结论：现有论文的证据只支持“单位需求抽象”；真实需求是下一阶段扩展，不能把示意写成现场结论。
